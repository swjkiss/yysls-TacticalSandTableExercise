# 燕云十六声 · 百业战战术板

纯前端网页战术板，双击 `index.html` 即可运行，无需后端、无需安装、无需联网。

## 快速开始

1. 双击根目录 `index.html`，用浏览器打开
2. 首次进入会自动新建一份空白模板
3. 在左栏「地图」上传一张百业战真实俯视图（游戏内正交俯视截图：关 HUD、关标记、无特效）
4. 左栏「编队」建队伍、加流派人物，默认名按流派生成（如「翊翊1号」「双剑1号」），可直接改名
5. 点编队里的成员 → 点工具栏「人物标点」→ 在地图点击放下，完成布阵
6. 用工具栏补据点、区域、路径、文字、作战分区
7. 导出 JSON 或战术包（含底图）发给队友

底图也可以用游戏录像截图：进百业战或回放 → 自由视角拉到最高、压成正俯视 → 关 HUD 与标记 → 截图。

## 功能

- **底图**：上传本地图片（PNG/JPG），长边自动压到 4096；多地图资源管理、切换、删除
- **画布**：滚轮以指针为中心缩放（0.1x~32x）、空格/中键拖拽平移、小地图导览窗、适应画布
- **标点**：据点印章、控制区域（椭圆）、路径箭头（连续点击，双击/回车结束）、文字标签、人物标点
- **分区**：框放作战分区，可命名、设负责队伍、标识色、宽高、锁定；整体拖动
- **编队**：多队伍、流派人物、默认命名、自定义改名、流派切换、改名与地图标点双向同步
- **属性**：右栏编辑选中对象属性；底图透明度/亮度/对比度由后续迭代接入
- **导入导出**：导出当前模板 JSON / 含底图战术包 / 复制到剪贴板；导入校验、冲突覆盖或另存
- **存储**：localStorage 存模板索引与偏好，IndexedDB 存模板全文与底图；编辑防抖 500ms 自动保存
- **快捷键**：V 选择 / 1 据点 / 2 区域 / 3 路径 / 4 文字 / 5 人物 / 6 分区；Ctrl+Z 撤销、Ctrl+Y 重做、Delete 删除

## 数据说明

所有模板与底图只保存在当前浏览器的本地存储，不上传任何服务器。清除浏览器数据会清空模板，重要战术请先导出备份。
