使用说明

① 快速上手

默认有防守队 / 机动队 / 指挥组三队。新建方案时会自动带入防守队 / 进攻队 / 指挥组三队与 7 名固定人物（翊翊1/2号、明川1号、八方1号、双剑1/2号、总指挥，开局站位已摆好），直接改名/换人即可用。点队伍标头选中它为目标队（高亮显示「目标」角标）后，点左侧流派库的人物即加入该队；再把人物拖到地图或点左侧人物后点地图布阵。在右侧属性面板改名字（如「翊翊1号」）、选流派、定队伍与本阶段意图。

注意：点左侧人物后会进入「待放」状态（卡片虚线闪烁），点一次地图放下后即自动结束，不会重复放置。想换个位置，再点一次该人物重新「待放」再点地图，或直接拖动地图上已有的标记。按 Esc 可取消待放。

左侧人物头像右下角的绿点和「阵」标记表示该人物本阶段已布阵到地图；未布阵显示「—」。选中人物后，地图上对应的标点会金色脉冲高亮，方便定位。

② 地图标点

选中央工具栏的标点工具（文字 / 集火 / 防守 / 箭头 / 区域 / 怪），在地图点击落点；拖动可移动，双击标点可取消，选中后可在右侧改名、写备注、改颜色。

箭头支持任意方向：选中箭头后，拖动它末端的金色圆点即可自由旋转（按住 Shift 吸附 15°）；也可在右侧「箭头方向」的方位盘里点八个方向，或用滑杆、键盘 ← → 精确调整。

③ 缩放与局部部署

滚轮以光标为中心缩放；✥ 工具或鼠标中键拖动平移；⊞ 工具框选一块区域局部放大，便于精细布点；右下角小地图可点击跳转。⛶ 适应全图。

④ 五个阶段

顶部切换开局 / 前期 / 中期 / 后期 / 终局五个阶段，每个阶段的人物站位与标点相互独立，可分别布置一套战术。

⑤ 阵营与底图

游戏每局红蓝随机，底部图例的 我方⇄敌方 可点击切换颜色标识。地图工具栏 🗺 可上传新地图截图作底图（游戏改版后换图即可，标点位置不受影响）。

⑥ 流派与队伍自定义

流派库分 PVE / 邪修 两类：PVE 为 12 个官方固定流派（含新上线的破竹·樽），邪修 为 6 个 PVP 混搭打法（如双剑、绳镖奶、无名九枪，标「邪修」角标），顶部两个标签可切换。两类都可以点列表底部 ＋自定义 新增——新增时可选归入「PVE」还是「邪修」，自建流派带「自建」角标。悬停格子点 ✎ 可编辑名称、定位、分类与颜色（20 种明亮色）。

队伍编队：点标头任意处即选中该队伍为「目标」（之后点流派库加人直接进此队），同时会自动展开；点标头右侧 ▾/▸ 箭头 单独折叠/展开；标头 ✎ 改名、✕ 删队（队内人物会一并删除，可撤销）。

隐藏队伍：标头左侧的 隐 按钮可把该队从地图上隐藏（只留其他队伍便于对照），隐藏后卡片变暗并显示「已隐藏」、按钮变 显；再点 显 或布阵该队人物时会自动恢复显示。隐藏只影响地图显示，队伍和人物数据都还在。

人物卡片点 ⇄ 或在右侧「所属队伍」下拉可改其队伍；卡片上的 ✕ 可快捷删除该人物（可撤销）。

配色规则：地图上人物标点的颜色 = 该人物的流派颜色，与左侧卡片头像同色（同流派在地图上同色）；换队伍不会改变标点颜色。流派/队伍的标识颜色提供 20 种明亮色可选。

队伍高亮：在左侧点中某支队伍后，该队所有人物标点会套上队伍色光圈并缓缓呼吸，左侧该队卡片也用同色描边发光——一眼就能看出这支队伍在地图上的位置分布；切到别的队伍，光圈会跟着切换。

⑦ 保存与分享

数据自动保存在本机浏览器，刷新不丢。导出 JSON 会把方案、自定义流派、底图和阵营设置一起打包；对方导入 JSON 即可还原整套战术。撤销 / 重做：Ctrl+Z / Ctrl+Y。
