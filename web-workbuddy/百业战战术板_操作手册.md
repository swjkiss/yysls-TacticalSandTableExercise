# 百业战战术板 · 操作手册

> 面向《燕云十六声》百业战指挥与队员的战术板使用指南。
> 配套工具：`百业战战术板/index.html`（浏览器直接打开即可，无需安装、无需联网）。
> 版本：2026-11-23

---

## 一、快速开始

### 1. 打开工具

双击打开 `百业战战术板/index.html`。页面顶部会提示"建议全屏显示"——点右上角 **全屏显示** 按钮，或按 **F11**，布置空间更大。提示条可点 ✕ 关闭（关闭后不再出现）。

### 2. 认识界面

```
全屏提示条（可关闭）
───────────────────────────────────────────
顶栏：方案切换 | 开局/前期/中期/后期/终局 | 撤销 重做 | 导入 导出 | 说明
───────────────────────────────────────────
左栏        中央地图画布              右栏
流派库      标点工具条                属性面板
队伍编队    地图 + 标点 + 小地图        （选中对象后编辑）
───────────────────────────────────────────
状态栏：方案 | 阶段 | 坐标 | 统计
```

- **左栏**：选人、编队的地方；
- **中央**：真实百业战地图，所有站位和标点都画在这里；
- **右栏**：点选人物/标点后，在这里改名字、意图等；
- 首次打开已预置一套示例战术（防守/机动/指挥组三队 + 7 个人物 + 五个阶段的标点），可直接改，也可新建自己的方案。

## 二、编队与加人

### 1. 三支默认队伍

| 队伍 | 颜色 | 典型职责 |
| --- | --- | --- |
| 防守队 | 墨绿 | 守自家野区与塔（预置牵丝、裂石、八方） |
| 机动队 | 朱砂红 | 绕后偷塔、推进（预置双剑） |
| 指挥组 | 古铜金 | 指挥位（战场货币施放者） |

队伍名和颜色都可以改：点标头 **✎** 会弹出编辑框，名称和颜色一起改（**10 色可选**）。

**两种颜色的分工要分清：**

| 颜色 | 用在哪 | 说明 |
| --- | --- | --- |
| **流派色** | 地图上人物标点的底色、左侧人物卡头像、属性面板角标 | 同一流派的人在地图上同色；换队伍**不会**改变它 |
| **队伍色** | 队伍标头色块、换队菜单、**选中队伍时的光圈** | 只表示"这人属于哪支队伍" |

**选中队伍 → 地图高亮**：在左侧点中某支队伍后，该队所有人物标点会套上一圈**队伍色光圈**（带呼吸动效），左侧该队的卡片也用队伍色描边发光。切到另一支队，光圈立刻跟着换。想快速看清"防守队站哪、机动队在哪"，点一下队伍就行。

### 2. 队伍的基本操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 设为"目标队"（新加的人进这队） | 点队伍**标头任意处**（名字、圆圈、空白都行），该队会高亮并显示「目标」角标 |
| 展开 / 折叠某队 | 点标头最右侧的 **▾ / ▸ 箭头**（只折叠，不改变目标队） |
| **隐藏 / 显示队伍** | 标头左侧的 **隐 / 显** 按钮：隐藏后该队人物从地图消失，卡片变暗并显示「已隐藏」，便于只看其他队伍 |
| 队伍改名 / 换颜色 | 标头上的 **✎**：弹窗里同时改名称和**颜色（10 色可选）** |
| 删除队伍 | 标头上的 **✕**（⚠️ 队内人物会一并删除，可用 Ctrl+Z 撤销） |
| 新建队伍 | 左栏"队伍编队"右侧的 **＋ 建队**，同样可选名称 + 10 色 |

> 小技巧：点标头选中队伍时，如果该队是折叠状态会自动展开，方便直接看到队内成员。

### 3. 添加人物

1. 先点某队的**标头**把它设为目标队（默认目标是第一队，标头有「目标」角标）；
2. 在左栏"流派库"点一个流派，人物就加入目标队；
3. 在右栏把名字改成你要的，如「翊翊1号」「双剑1号」。

**流派库分两类**，顶部标签切换：
- **PVE**：12 个官方固定流派（含破竹·樽）+ 你自己加的 PVE 流派；
- **邪修**：6 个 PVP 混搭打法（双剑、绳镖奶、无名九枪、手甲唐刀、双枪、九重九剑，带"邪修"角标）+ 你自己加的邪修流派。

流派可随意搭配，不限组合、不限数量。格子上悬停点 **✎** 可编辑流派（名称/简称/定位/分类/颜色）。

**新增自定义流派**：两个标签页底部都有 **＋ 自定义 / ＋ 自定义邪修**，点开填写名称即可。弹窗里可以选归入「PVE 流派」还是「邪修 / PVP」——在邪修页点新增，默认就归邪修；保存后会自动切到对应标签页，能立刻看到。

### 4. 人物卡上的快捷按钮

| 按钮 | 作用 |
| --- | --- |
| **⇄** | 弹出队伍列表，换到别的队 |
| **✕** | 删除该人物（可 Ctrl+Z 撤销） |

也可以在右侧属性面板的"所属队伍"下拉里改队伍。

## 三、布阵（把人放到地图上）

### 两种方式，任选其一

**方式 A：点选布阵（推荐）**
1. 点左栏某个人物卡片 → 卡片虚线闪烁、显示"待放"；
2. 在地图上点一下 → 人物放下，**自动退出待放**，不会重复放置；
3. 想换位置：再点一次该人物重新"待放"再点地图，或直接拖动地图上的标记。

**方式 B：拖动布阵**
- 直接把人物卡片拖到地图落点。

按 **Esc** 随时取消"待放"状态。

### 看懂人物状态

- 人物头像右下角有**绿点**、卡片右侧显示「**阵**」= 本阶段已布阵到地图；
- 显示「**—**」= 本阶段还没安排；
- 点选人物后，地图上它的标点会**金色脉冲高亮**，一眼找到。

### 改人物意图

点地图上的人物标点（或左栏人物卡片）→ 右栏"本阶段意图"里选：站位 / 集火 / 防守 / 推进 / 偷塔 / 搬树。还可改名字、流派、队伍、备注。

### 撤下 / 删除

- **双击地图上的人物标记** = 撤下本阶段布阵（人还在，可撤销）；
- **双击标点** = 删除该标点（可撤销）。

## 四、地图标点

中央地图工具条的标点按钮：

| 按钮 | 含义 | 用途举例 |
| --- | --- | --- |
| 文 | 文字 | "这里集合""注意埋伏" |
| ⚔ | 集火 | 集火目标点 |
| 盾 | 防守 | 防守要点 |
| ➤ | 路线箭头 | 推进、搬树、绕后路线，**可指定任意方向** |
| ◯ | 区域圈 | 责任区范围 |
| 怪 | 野区怪 | 野怪/首领刷新点，可备注刷新时间 |

**操作**：点选工具 → 在地图点击落点 → 拖动可移动 → 双击删除 → 选中后右栏改名/写备注/**改颜色（20 色可选，六类标点都生效，区域标点的虚线颜色也会跟着变）**。

**箭头方向（任意角度）**，三种调法任选：

| 方式 | 操作 |
| --- | --- |
| 直接拖 | 选中箭头 → 拖动它**末端的金色圆点**绕中心旋转（按住 Shift 吸附 15°） |
| 方位盘 | 右栏「箭头方向」九个格子里点八个方向之一（0°向右、90°向下、180°向左、270°向上） |
| 精调 | 拖方向滑杆，或按键盘 **← / →** 每次 5°（按住 Shift 每次 15°） |

方向会随方案一起保存，切换阶段/刷新页面后保持。老战术里的箭头默认指向右侧，重新拖一下即可。

## 五、缩放与局部部署

| 操作 | 方式 |
| --- | --- |
| 缩放 | 鼠标滚轮（以光标为中心，指哪放大哪）、底部 ＋/− 按钮 |
| 平移 | 工具栏 ✥ 或鼠标中键拖动 |
| **局部精细部署** | 点 ⊞ 工具，在地图上框选一块区域（如某座塔区），自动放大后精细布点 |
| 快速定位 | 右下角小地图，点击/拖动视口框跳转 |
| 复位 | 点 ⛶ 或底部"复位"回到全图 |

缩放和平移不影响战术数据——导出的坐标始终是地图归一化位置。

## 六、五个阶段

顶部 **开局 / 前期 / 中期 / 后期 / 终局** 五个 Tab。每个阶段的人物站位、标点**相互独立**，可以按一场比赛的 5 个时间点分别布一套：

| 阶段 | 建议摆什么 |
| --- | --- |
| 开局 | 出门路线、第一波野区站位 |
| 前期 | 守野区、盯上下半场 |
| 中期 | 推塔 / 争首领、偷塔路线 |
| 后期 | 杀鹅搬树、强开敌方复活点 |
| 终局 | 收尾决战、最后的兵线处理 |

新加的两个阶段（开局 / 终局）默认是空的，摆什么完全由你决定。切换阶段时，左栏人物的"阵/—"会随该阶段的布阵情况变化。

## 七、阵营与底图

### 阵营颜色

百业战每局红蓝随机，"我方"不一定是红。地图下方图例的 **●我方 ⇄ ●敌方** 可点击切换颜色标注（旁有"阵营随机·点击切换"提示）。这只改标注，不改地图地形。

### 更换底图（游戏改版时）

1. 地图工具栏点 **🗺**；
2. 选 **上传图片**，选一张新的地图截图（自动压缩）；
3. 主图和小地图同步换图，**已布置的人物和标点位置不变**；
4. 想换回原图：🗺 → **恢复默认原图**（回到内置的彩色战场底图）。

> 默认底图是游戏内实机地图的彩色版。底图采用**归一化坐标**，换图后所有标点与人物按比例落位，不会跑偏。

## 八、保存与分享

- **自动保存**：所有改动自动存在本机浏览器，刷新不丢。顶栏显示"已保存"。
- **导出 JSON**：顶栏"导出 JSON" → 下载一个文件，内含方案、自定义流派、底图、阵营设置。发到群聊给队员。
- **导入 JSON**：队员点"导入 JSON" → 选文件 → 作为新方案载入，看到的就是完全一致的战术。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（或顶栏按钮），覆盖增删改、换图、删队等绝大多数操作。

> ⚠️ 清理浏览器数据会丢失本地战术。重要战术请定期**导出 JSON 备份**。

## 九、方案管理

顶栏"战术方案"下拉可切换多套方案；旁边的：
- **＋** 新建方案（**自动带入标准阵容**，见下）；
- **⧉** 复制当前方案为副本；
- **✕** 删除当前方案。

### 新建方案自带什么

点 ＋ 输入名称后，新方案不是空地，而是已经备好一套标准阵容：

| 队伍 | 颜色 | 预置人物 |
| --- | --- | --- |
| 防守队 | 墨绿 | 翊翊1号、翊翊2号、明川1号、八方1号 |
| 进攻队 | 朱砂红 | 双剑1号、双剑2号 |
| 指挥组 | 古铜金 | 总指挥 |

- 7 个人物沿用标准流派（牵丝·翊×2、牵丝·霖、裂石·威、破竹·风×2、鸣金·虹）；
- **开局阶段**的站位已按常规防守/偷塔布好，双剑2号留作待布阵；
- 自定义标点（箭头、区域圈等）全部为空，从零开始画自己的战术；
- 目标队默认为**防守队**。

不需要的人直接点卡片上的 ✕ 删掉，想加人点队伍标头设为目标后点流派库即可。

新建/复制/切换方案后，"目标队"会自动设为新方案的第一队，不会出现选中错乱。

## 十、常见问题（FAQ）

| 问题 | 解答 |
| --- | --- |
| 点地图总是重复放同一个人？ | 现在放下会自动退出"待放"，不会再重复。想重放就再点一次人物。 |
| 找不到"目标队"高亮？ | 只有一队是目标，标头带「目标」角标，点任意队伍标头即可切换；新建方案后目标会重置到第一队。 |
| 派生的新手字体看着别扭？ | 页面采用宋体风格呼应游戏国风，可在浏览器缩放（Ctrl +/-）调整。 |
| 想全屏但按钮没反应？ | 部分浏览器限制脚本触发全屏，改用 **F11** 手动全屏即可。 |
| 地图标点放不上？ | 检查是否点在已有标记上（会被当成选中/拖动）；换空白处点。 |
| 换图后标点错位？ | 标点用归一化坐标，换图不会错位；若看着偏，点 ⛶ 复位视角。 |
