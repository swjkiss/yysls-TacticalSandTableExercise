操作指南

一分钟上手

  1. 在模板库新建模板，填写名称、分类与底图。
  2. 用顶部工具栏放置标点、添加流派人物、画路线或写文字。
  3. 选中对象后在右侧“属性”里改名称、颜色、状态与备注。
  4. 按 Z 框选一块区域放大，精细摆位；点“返回全图”或按 0 回到全局。
  5. 内容会自动保存到当前浏览器，重要版本用“导出 JSON”留档。

底图替换

“底图”区块可选择已登记的底图，或上传 JPG/PNG/WebP。上传图片会自动压缩后保存在当前浏览器。

所有对象坐标按 0–1 归一化保存。更换底图只改变背景图，不会移动已放置的标点与人物；不同地图的视觉比例差异需要你自行微调。

模板会记下所使用的底图 ID。换到没有该底图的浏览器时，会自动回退到默认底图并给出提示。

保存与分享

编辑内容自动保存在浏览器 localStorage，不登录、不上传服务器。清理浏览器数据会丢失模板，请定期导出 JSON。

导入的 JSON 会先校验格式、版本、字段与数量上限，再让你选择“作为新模板”或“覆盖现有模板”。

自动保存失败，最近的改动可能没有写入浏览器。
